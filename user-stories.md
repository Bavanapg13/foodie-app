# Foodie – User Stories

## 1. User Registration
As a new user, I want to create an account using my username, email, and password so that I can access the Foodie application.

## 2. User Login
As a registered user, I want to log in using my email and password so that I can access my account and saved recipes.

## 3. Browse Recipes
As a user, I want to browse available recipes on the home screen so that I can discover different dishes.

## 4. Search Recipes Through an API
As a user, I want to search for recipes using the Explore section so that I can discover recipes fetched from an external recipe API.

## 5. View Recipe Details
As a user, I want to view a recipe's image, ingredients, instructions, preparation time, and other details so that I can decide how to prepare it.

## 6. Manage Favorite Recipes
As a user, I want to add or remove recipes from my Favorites so that I can easily access recipes I like.

## 7. Create and Manage Personal Recipes
As a user, I want to add, edit, and delete my own recipes so that I can maintain my personal recipe collection.

## 8. Save App Data
As a user, I want my favorite recipes and personal recipes to remain saved after closing and reopening the application so that I do not lose my data.

## 9. Manage Settings and Notifications
As a user, I want to manage application settings and enable notifications so that I can customize my app experience and receive recipe reminders.s
